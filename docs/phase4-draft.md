## 5. 推荐组合

**前提已变：同族升级无效（flash→flash-max 持平）、MiniMax 重测更差（1/15），A 的
胜率显著下调。** 推荐组合随之重排——**B 为主轴推进，A 收缩为"GLM + Claude 两个
跨家族候选的条件尝试"，C 仍仅作补差选择：**

1. **立即（无需花钱）：** 启动 B3/B4（文档尾差与点击检查）+ 推进 B2/B7 的用户侧安排。
2. **A 条件尝试（用户决策花费）：** 等 GLM-5.3-Flash S1 结果回填——
   - GLM S1 通过 → 花 <$2 做 GLM S2 首跑；≥8/15 补第二跑，达标后立即做 B1、A7、A8；
   - GLM S1 不达标 → **按既定决策关闭方向 A**，不再新增候选；
   - GLM 通过但 S2 未达标 → 仅再试 **claude-sonnet-5-5**（网关 `basalt-iq3-xxs` 路由）
     一个候选；Claude 也不达标即关 A。
3. **B 为主轴：** 无论 A 成败都推进 B3/B4/B6/B2/B7；A 关闭时 B1 维持 fake 披露现状
   （诚实记录，不造假），并把省下的预算/时间转投 B2（真人走查）与 C2/C1（维度 1 尾差）。
4. **预估总分：**
   - GLM 或 Claude 达标 + B：约 **90–91**；再补 C2/C1 冲 **92**。
   - A 关闭 + B 全量落地：约 **82–83**（维度 2 封顶 4.0 锚点、维度 3 因缺真实片段
     封顶 8.5）；若再加 C2/C1 可到 **~84**——**过不了 92 门槛**，作品集以
     "工程与安全证据 9 分 + 诚实边界声明"为卖点，而非模型能力分。
