# 能不能麻烦你在自己的 Windows 机器上装一次 OpsPilot，并走一遍？

你好——先谢谢你。这封信里有你在开始之前需要知道的全部信息，读完这一封就
够了；真正的操作步骤在另一个文件里，也就是我一起发给你的走查脚本
`installer-verification.md`（在项目的 `docs` 目录下）。

## 这是什么

**OpsPilot** 是一个面向客服与账务的 AI 运营代理。它接过一张工单，查出该
适用的策略，给出一个动作建议——**而当这个动作要动钱的时候，它会停下来，等
一个人批准**。它整个跑在你自己机器上的 Docker 里。源代码是公开的。

先说一件，免得你在走查时被吓到：**这个项目里的账务是模拟的。** 它背后没有
任何支付通道。走查里让你批准的那笔退款，只是往一个测试文件里写一行记录，
**没有任何钱发生移动**。

## 为什么找你

在一台干净的机器上装好 OpsPilot 并走一遍，**是本项目自己完成不了的那一项
验收**，而写它的人也不能替自己完成——自己搭过的人都知道哪儿有棱角。在这件事
通过之前，我们连发布都特意按着不发。所以我需要**一个从没用过它的人**。

**被测的不是你，是这份说明。** 走查脚本是写下来了，但项目之外还没有人
照着跑过，我也不知道它写得够不够用。哪一步读不懂、哪儿过不去，那**正是**
我要的发现。

## 你需要什么

- **一台 Windows 机器**——版本 10 或 11，64 位。普通笔记本就行。
- **Docker Desktop**，装好并处于**运行状态**。下载地址是
  <https://www.docker.com/products/docker-desktop/>。如果你从没用过，
  先装上、启动它，等它安顿下来（大约一分钟）再开始。
- **大约 6 GB 空闲磁盘。**
- **大约 15 分钟。** 首次启动是最慢的一次：应用要在**你的机器上从源码构建
  三个容器镜像**，所以会滚很久的输出。**这是正常的**，它本来就是这样设计的
  ——走查脚本给的时间是 5 到 15 分钟。之后的启动只要几秒。
- **一个屏幕录制工具**——任何能输出 MP4、能限制码率的都行，不需要指定某个
  软件。

就这些。你**不需要**这个项目的源码、不需要 Node、不需要构建工具，也不需要在
任何地方注册账号。

## 你要做的事

1. **拿到安装包**——一个文件，`OpsPilot-Setup-<version>-x64.exe`。
   - **你有 GitHub 账号**的话，可以自己去项目的 CI 运行页下载；走查脚本的
     「安装包从哪来」一节写了确切路径。
   - **没有账号**也没关系，这是最常见的情况：**安装包是我发给你的**，和这
     封信一起。从 CI 下载构建产物需要登录 GitHub 账号，所以这一步由我替你
     做。两种方式拿到的是**同一个文件**——由项目的 CI 从**某一个具体的
     commit** 构建出来的——我也可以告诉你它出自哪一次运行。
2. **照着走查脚本做。** 它是一份一步一步的手册：每一步都写了你应该看到
   什么，以及没看到时该怎么办。
3. **全程录屏。** 在双击安装包**之前**就开始录，**录多久停在哪里，走查脚本的
   录屏那一节会写清楚**。这段录屏是这个项目**现在真正缺的那份证据**：仓库里
   有应用的截图，但**没有**"应用来到一台从没见过它的机器上"的样子。那一节
   还写了文件名、格式和大小——**请照着来，因为文件名是被检查的**。你手上没有
   这个仓库，也不需要有：**把录屏留在录下来的地方，连同报告一起交给我**，
   我来放进仓库。
4. **按走查脚本最后一节列的清单回报。**

## 卡住了怎么办

**停下来，告诉我。请不要自己发明一个绕过去的办法。** 走查脚本里的每一步都
是写成**别人可以核对**的，所以你绕过去做出来的结果谁也用不了——而且**挡住
你的那件事，很可能正是我需要知道的事**。

脚本里列出了它已知的失败情况，每一种都写了该怎么办；撞上了就照它说的做。
如果撞上的是**它没列的**，或者某一步做的和它写的不一样，就停在原地，把你
看到的记下来发给我。

**一份走到一半、卡在第一个问题、然后带着清楚的描述回来的走查，对我来说是
好结果。** 一份"全都正常"但其实不正常的报告不是。

## 你要回报什么

- 你看到的**原文**——整段窗口日志，不要转述。
- 最后一节要你跑的那两条命令的输出。
- 你的 Windows 版本和 Docker Desktop 版本。
- 那一次启动是这台机器上的**首次启动**，还是重复启动。
- 你装的是哪个安装包、它从哪来——如果是我给的，你说一声就行。
- **你有没有录屏**；录了的话，写上**文件名**和**大小（字节数）**。

## 一件请不要发出来的东西

这个项目是公开的，安装包你尽管留着、尽管写你的发现，都没问题。但
**请不要把 operator token、或者任何 `.env` 文件的内容贴进你的报告。**
应用会在你机器上首次启动时生成自己的 token，那是个秘密——尽管它后面并没有
什么值钱的东西。如果你要发的某一行里不小心带上了它，请把它替换成
`[redacted]`，并说明你做过这个替换。

再次谢谢你。这件事只有陌生人才能替项目做掉，而你的报告就是把它结掉的那一步。
