# OpsPilot v0.2.0 — 真人交互式走查脚本（2026-11-15）

**目的：** 对已发布的 v0.2.0 安装包做一次「真人、双击、可交互」的干净机走查。
headless 走查（2026-11-15，`docs/installer-verification.md`）已覆盖功能面；
本脚本补齐它不覆盖的部分：**双击安装器、SmartScreen 提示、桌面图标、
窗口交互、菜单语言切换、退出行为**。

**走查人要求：** 未参与本项目构建；Windows 10/11 x64；已装 Docker Desktop；
约 6 GB 空闲磁盘；全程约 20–30 分钟（其中冷启动等 Docker 5–15 分钟）。
